Install without the launcher.

Already have Fabric? Add the mod by hand.

  1. Install Fabric Loader for Minecraft 1.21.11 from fabricmc.net.
  2. Put Fabric API in your mods folder.
  3. Download the Nimbus .jar and put it in the same folder.
  4. Start the Fabric profile and press Right Shift.

Questions

Is Nimbus allowed on multiplayer servers?

It only adds HUD tools, zoom and fullbright. Some servers ban fullbright or zoom, so read your server's rules and switch those modules off if needed.

Which Minecraft versions work?

1.21.11 on Fabric. Other versions may come later.

Will it slow my game down?

Very little. Every module can be switched off, and switched-off modules do no work.

Where does the launcher keep its files?

In %APPDATA%\.nimbus. The Open folder button in the launcher takes you there.
